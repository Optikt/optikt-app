# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. Do **not** open a public issue.

- Open a **private vulnerability report** under the Security tab of this repository (recommended).
- Include the affected version, a description of the issue, reproduction steps, and the potential impact. If possible, provide a proof of concept.
- Do not include sensitive data, credentials, or real customer records.

## Response

We aim to acknowledge reports within 3 business days and provide an assessment of the issue. Fixes are released as soon as possible depending on severity. We'll keep the reporter informed of progress.

## Scope

Applies to the Optikt application and its dependencies. Issues in third-party dependencies are handled via Dependabot / upstream patches whenever available.
