Notas del rediseño

Mockup interactivo — prueba editar, agregar y borrar

1
Cero cards anidadas

La lista de artículos es plana: filas separadas por hairlines de 1px. El editor se expande en línea (acordeón) con fondo tenue — nunca una card dentro de otra card.

2
Máximo 2 niveles visuales

Drawer blanco → filas / editor gris claro. El ojo nunca atraviesa 3 bordes para leer un dato.

3
Descuento unificado

Mismo control segmentado $ fijo / % en artículo y en orden. El sufijo y el precio final se recalculan al instante.

4
Receta compacta

OD y OI en dos columnas de 3 campos (Esf · Cil · Eje), cada ojo con su toggle. Tratamientos como chips, no como checkboxes apilados.

5
Footer siempre visible

Resumen editable, descuento de orden, motivo de auditoría y acciones viven en el footer sticky: cero scroll para guardar.

6
Densidad con jerarquía

Filas de ~64px, acciones solo al hover, tipografía 13px. El espacio se usa para datos, no para bordes.

7
Agregar sin fricción

Fila punteada al final → menú de 3 tipos (Cristal / Producto / Ítem libre) → se crea la fila y se abre su editor listo para completar.
